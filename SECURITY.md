# Security

Driftless runs as a hook of your coding agent, on your machine, in folders you may have cloned from anyone. What it does
about that is in [Safety](docs/safety.md).

## Reporting a vulnerability

Please report it privately: on this repository, **Security → Report a vulnerability** (GitHub's private vulnerability
reporting). Do not open a public issue for it. Say what an attacker controls (a cloned folder, a file in `.driftless/`,
an environment variable…), what Driftless then does, and on which operating system and agent.

Fixes go into the next release, with credit in the changelog unless you prefer otherwise.

## Supported versions

Only the latest release is supported.
